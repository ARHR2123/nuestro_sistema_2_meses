# Nosotros v2.0 ❤️

Mini web romántica para celebrar dos meses.

## Personalización rápida

1. Abre `index.html`.
2. Cambia `A & E` y los textos que quieras.
3. Reemplaza las imágenes:
   - `img/foto1.jpg`
   - `img/foto2.jpg`
   - `img/foto3.jpg`
   - `img/foto4.jpg`
4. En `css/styles_main.css` puedes modificar tipografías, tamaños y fondo.
5. En `index.html`, cambia la fecha de "Próxima actualización".

## Publicarla gratis

### GitHub Pages
- Crea un repositorio.
- Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
- En Settings > Pages, activa Pages desde la rama principal.

No necesitas servidor: es una web estática.
